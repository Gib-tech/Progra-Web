Descripción del proyecto: El proyecto es una página web para leer cómics o mangas, ya sea cargando archivos CBR/CBZ o
subiendo imágenes JPG/PNG para guardarlas en una carpeta que podrá ser descargada en los formatos CBR/CBZ

Descripción de las carpetas: De momento, el proyecto todavía se sigue desarrollando, por lo que todo se guarda en local storage, sin embargo, las carpetas están divididas en los JS y CSS que contienen
los respectivos archivos con el código del diseño y funcionamiento de cada html, los únicos que comparten un css son iniciar.html y registrar..html que usan ambos acceso.css
